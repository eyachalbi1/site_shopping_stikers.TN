# Dossier images

Mets ici les photos de tes 17 stickers.

Nomme chaque fichier exactement comme ceci (en minuscules, en .jpg) :

sticker1.jpg
sticker2.jpg
sticker3.jpg
...
sticker17.jpg

Le site va automatiquement afficher chaque image à sa place sur la page,
dès qu'un fichier avec le bon nom est ajouté ici. Pas besoin de modifier
le code : tant que le nom correspond, l'image apparaît, sinon un cadre
"image manquante" reste affiché à sa place.
